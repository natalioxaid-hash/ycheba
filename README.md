# Учёба детей

- `kolizey/` — презентация Ильи «Колизей» (pptx, фотографии, скрипт сборки build.js)
- `doklad/` — доклад, сообщение и презентация «Эволюция телефона» (docx, pdf, pptx)
- `egipet-spb/` — задание «Древний Восток в Петербурге», 8 класс, уроки 3—5: исходное задание и заполненные таблицы (docx)
- `petrogradka/` — проект «Петроградский район», 8 класс: темы, рабочий лист, цель и задачи (острова); темы для друга: спорт, техника, теннис, музыка, «Ленфильм» (docx)
- `algebra-8/` — алгебра, 8 класс, 2 четверть: шпаргалка (docx, pdf), цветная памятка (pdf, png) и памятки по свойствам корней и степеней и по квадратным уравнениям (pdf, png)
- `geometriya-8/` — памятка по геометрии, 8 класс, 2 четверть: площади фигур, теорема Пифагора, подобие треугольников (pdf, png)
- `drobi-4/` — памятка по дробям, 4 класс (Петерсон): доли, сравнение, задачи на части, смешанные числа, сложение и вычитание (pdf, png)
